# Just This: legal pages

Static pages for the Android app **Just This** (`com.scorpiuslabs.showjustthis`), served by GitHub Pages.

- `privacy.html`: privacy policy (Play Console › App content › Privacy policy)
- `terms.html`: terms of use
- `index.html`: small landing page (can be the Play listing website)

Publish: push to GitHub, then Settings › Pages › Deploy from branch `main`, folder `/ (root)`.
If the repo is `beingshaban79/justthis-legal`, the privacy URL is
https://beingshaban79.github.io/justthis-legal/privacy.html
(the app links to it from `src/config.ts` › `PRIVACY_URL`).
